This python app was made with the intention to turn automatic the proccess of writing reports for missing keys. To use it, paste the spreadsheet on the website (https://enviadorchavesprog.streamlit.app/) and set the corresponding columns if needed.
The Gmail button is also pre-filled to make my personal use easier.

Este aplicativo em Python foi criado para automatizar o processo de elaboração de relatórios sobre chaves ausentes. Para utilizá-lo, cole os dados da planilha no site (https://enviadorchavesprog.streamlit.app/) e determine as colunas correspondentes.
O botão do Gmail também já vem preenchido para facilitar meu próprio uso.
