This python app was made with the intention to turn automatic the proccess of writing reports for missing keys. To use it, paste the spreadsheet on the website (https://enviadorchavesprog.streamlit.app/).
The output is currently hardcoded based on the columns, due to change, and the header from the Gmail button is also pre-filled to make my own personal use easier.

Este aplicativo em Python foi criado para automatizar o processo de elaboração de relatórios sobre chaves ausentes. Para utilizá-lo, cole os dados da planilha no site (https://enviadorchavesprog.streamlit.app/).
Atualmente, a saída é definida de forma fixa (hardcoded) com base nas colunas — estando sujeita a alterações —, e o cabeçalho do botão do Gmail também já vem preenchido para facilitar meu próprio uso pessoal.
